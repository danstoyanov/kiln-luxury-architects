# SIN-37 / K06 — Identity proposal

K06 определя визуалната система за човешко ревю. [DESIGN.md](../../DESIGN.md) е договорът за K07 и следващите етапи; application source, зависимости и финални изображения не са променяни.

## Избрана посока

В текущия разговор потребителят избра **„Материална архитектура“** и потвърди **запазване на геометричното KILN**. Предложението превръща това в минерална основа `#F2F1ED`, graphite `#282B28`, fired clay `#805542`, Switzer за четене/заглавия и Panchang само за името. Знакът споделя първия екран с по-голям архитектурен кадър. Конкретните стойности остават предмет на PR ревюто.

Спрямо временната основа: по-неутрален фон, по-голям hero кадър, description/CTA вдясно от името на desktop, широк Ridge crop, една проектна колона при 768px, точни правила за изображенията, controls и reduced motion. Няма нов draw: запазена е посоката The name as a monument, seed 35, с уточнения според избора на потребителя.

Фотографията е съществуващият временен hero от Aalo Lens / Unsplash, с видими source/license връзки. Не е генерирана тук и не е финален KILN проект. [Източник и условия](../temporary-assets.md). Страницата на таблото изрично го обозначава като review document; визуалните примери за hover/focus са specimens, не форма за изпращане.
