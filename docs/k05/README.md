## Повторно изпълнение

При вече построено `out/`, в отделен терминал:

```sh
npm run preview -- --listen 4186
```

Проверките по подразбиране записват в нови подпапки на игнорираната `.taste-skill/checks/`:

```sh
node scripts/check-k04.mjs http://localhost:4186
node scripts/check-k05.mjs http://localhost:4186
```

За нов комплект за ревю добави `--out docs/k05/<new-run>`. Избери ново име при всяко изпълнение. `--update-baseline` е изрично разрешаване на презаписване и не е част от нормалната команда; не се използва за ежедневни проверки. K04 документът описва историческото изпълнение, а тези команди са актуалният начин за повторение.
